# AI Translator Keyboard

AI Translator Keyboard is a smart Android keyboard app that helps users type and translate text in multiple languages directly from the keyboard. The app supports English and Urdu typing, voice-to-text input, instant translation, and a modern user-friendly interface.

## ♫ Features

- Type in English or Urdu and get instant translations
- Voice-to-text input support
- Multi-language translation
- Modern, clean user interface
- Optimized for mobile devices

## 🔾 Tech Stack

- Language: GDScript (Godot)
- Framework: Godot 4
- Platform: Android

## 📠 Getting Started

1. Open this project in Godot 4.
2. Run the project on an Android device or emulator.
3. Start typing and translating!
